## 撮影手順

1. n8n Cloud にワークフローをインポート
2. 各ノードを設定してテスト実行
3. キャンバス全体を表示して `workflow-overview.png` を保存
4. 各ノードをダブルクリックして設定画面をスクリーンショット
5. 実行後のSheetsとDiscordの画面をスクリーンショット
