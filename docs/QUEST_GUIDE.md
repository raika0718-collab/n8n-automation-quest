# クエスト攻略ガイド

```
あなたは自動化ギルドの新人技師。
失われた情報監視システムを復旧せよ。
```

---

## Quest 1: 情報源を接続せよ

**使うノード:** RSS Feed Trigger

ギルドの情報網を復旧する最初のミッション。
RSSフィードからニュースデータを自動取得するノードを確認しよう。

### 確認ポイント

- [ ] ノード名「Quest 1: RSS接続」をダブルクリック
- [ ] URLが `https://techcrunch.com/feed/` になっているか確認
- [ ] 必要に応じてURLを変更（日本語ニュースサイトのRSSなど）
- [ ] ノードを右クリック → 「Execute node」でテスト実行
- [ ] 記事データ（title, link, contentSnippet）が取得できればクリア

**ヒント:** RSSを提供しているサイトであれば、好きなサイトのURLに変えられます。
例: `https://www.nhk.or.jp/rss/news/cat0.xml`（NHKニュース）

## Quest 2: AIに情報を解析させよ

**使うノード:** OpenAI

取得したニュースをAIに渡して、3行要約と重要度スコアを生成させるミッション。

### 確認ポイント

- [ ] ノード名「Quest 2: AI解析」をダブルクリック
- [ ] OpenAI APIキーが設定されているか確認（Credentials欄）
- [ ] プロンプトを確認 — 「要約:」「重要度:」の形式で出力させていることを理解する
- [ ] 前のノードのデータ（`{{ $json.title }}`）が参照されているか確認
- [ ] OpenAI設定後に「Quest 1」からテスト実行してAI出力を確認
- [ ] 「要約:」と「重要度:」が含まれる出力が返ってきたらクリア

**ヒント:** gpt-4o-mini は安価で高速です。プロンプトを変えて
重要度の基準（AI関連 / 投資 / テックなど）を自分好みにカスタムできます。

---

## Quest 3: 記録装置へ保存せよ

**使うノード:** Google Sheets

AIが解析した情報を記録装置（Google Sheets）へ書き込むミッション。

### 確認ポイント

- [ ] ノード名「Quest 3: Sheets保存」をダブルクリック
- [ ] Google Sheetsの認証情報が設定されているか確認
- [ ] Document IDを自分のスプレッドシートIDに変更したか確認
- [ ] Sheet Nameが「AIニュース監視ログ」になっているか確認
- [ ] 保存列（Date, Title, Summary, Score, URL）が正しく設定されているか確認
- [ ] テスト実行してSheetsにデータが追記されたらクリア

**ヒント:** スプレッドシートIDはURLの `/d/` と `/edit` の間の文字列です。

---

## Quest 4: ギルドへ報告せよ

**使うノード:** IF + Discord Webhook

重要度スコアが高いニュースだけをDiscordへ報告するミッション。
情報の選別こそ、優秀な自動化技師の証だ。

### 確認ポイント

- [ ] 「重要度チェック (>=70)」ノードをダブルクリック
- [ ] 条件が `score >= 70` になっているか確認
- [ ] 数値を変えると報告の頻度を調整できる（低くすると多く通知）
- [ ] 「Quest 4: Discord通知」ノードのWebhook URIを設定
- [ ] メッセージ形式を確認 — タイトル・要約・スコア・URLが含まれている
- [ ] スコア70以上のデータでテスト実行してDiscordに通知が届いたらクリア

**ヒント:** IFノードのTrue側（上の矢印）がDiscord通知、
False側（下の矢印）は通知しない（何も起きない）です。
