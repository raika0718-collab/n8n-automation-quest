## 完成するもの

```
動画ネタ入力
  ↓
```

## Quest 1: 投稿文を生成せよ

**ノード:** Set + OpenAI（X投稿文）

### 確認ポイント

- [ ] 「Quest 1: 動画ネタ入力」ノードをダブルクリック
- [ ] `video_title` / `hook` / `summary` / `target` の4フィールドを確認
- [ ] これらを好きな動画テーマに変更してみる
- [ ] 「Quest 1: X投稿文生成」のプロンプトを確認
  - 140文字制限・フックで始める・CTA付き
- [ ] テスト実行してX投稿文を確認

**ポイント:** 入力データをSetノードで定義しておくことで、
プロンプトの変数参照が簡単になります。

---

## Quest 2: 魅力的なタイトルを作れ

**ノード:** OpenAI（YouTubeタイトル）

### 確認ポイント

- [ ] 「Quest 2: YouTubeタイトル生成」ノードを確認
- [ ] `$('Quest 1: 動画ネタ入力').item.json.video_title` の参照を確認
  - 別ノードのデータを名前で参照できる（n8nの強力な機能）
- [ ] 3案のタイトルと概要欄が生成されることを確認
- [ ] X投稿文生成とYouTubeタイトル生成が**並列**で動いていることを確認
  - ダイアグラム上で2本の矢印が同じSetノードから出ている
- [ ] 「投稿生成結果を合流」が両方の完了を待ってから後続へ進むことを確認

**ポイント:** 並列実行で処理時間を短縮できます。

## Quest 3: ハッシュタグを最適化せよ

**ノード:** OpenAI（ハッシュタグ）

### 確認ポイント

- [ ] 「Quest 3: ハッシュタグ最適化」ノードを確認
- [ ] X用 / YouTube用 / TikTok用の3種類が生成されること
- [ ] 並列で動いていた2つのOpenAIノードが「投稿生成結果を合流」を経由してここに入ることを確認

## Quest 4: 記録装置へ保存せよ

**ノード:** Code（Markdown整形） + Google Sheets

### 確認ポイント

- [ ] 「Quest 4: Markdown整形」Codeノードを開く
- [ ] `$('Quest 1: X投稿文生成').item.json` の参照を確認
  - 複数の前のノードのデータを一箇所で統合している
- [ ] `markdown` フィールドに整形されたテキストが入っているか確認
- [ ] Sheetsに保存される列（Date, Title, X_Post, YT_Title1等）を確認

**ポイント:** Codeノードは「n8n内のプログラマブルな接着剤」です。
前のどのノードのデータでも参照でき、データを自由に整形できます。
