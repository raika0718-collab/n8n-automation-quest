## 説明文

```
n8nをゲーム感覚で学べる「Automation Quest」シリーズ第1弾です。

【このテンプレでできること】
RSSフィードを15分おきに監視し、
OpenAIが記事を3行要約 + 重要度スコア判定。
重要度70点以上のニュースだけDiscordに通知し、
全記録をGoogle Sheetsに自動保存するシステムです。

【クエスト構成】
Quest 1: RSSノードで情報源を接続
Quest 2: OpenAI APIで記事を解析
Quest 3: Google Sheetsに記録保存
Quest 4: Discord Webhookでギルドへ報告

全4クエストをクリアすると、
実際に動くAI自動化システムが完成します。

【必要なもの】
・n8n（Cloud版の無料枠でOK）
・OpenAI APIキー
・Googleアカウント
・Discord Webhook URL

【含まれるもの】
・workflow.json（n8nにインポートするファイル）
・IMPORT_GUIDE.md（インポート手順）
・SETUP_GUIDE.md（各サービスの準備手順）
・QUEST_GUIDE.md（クエスト攻略ガイド）
・ERROR_GUIDE.md（エラー対処法）
・sample_output.md（期待出力サンプル）

【注意事項】
・本テンプレートにAPIキー等の認証情報は含まれていません
・各自のAPIキーを設定してご使用ください
・OpenAI API利用料は別途発生します（目安: 1記事0.01〜0.05円）

GitHub: [リンクをここに]
```
